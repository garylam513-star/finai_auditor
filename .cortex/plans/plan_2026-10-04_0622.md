## Context

The current `app.py` is a static Streamlit demo with hardcoded responses. We need to wire it to three live Snowflake services:

1. **Cortex Analyst** (REST API) — query `FINAI_AUDIT_DB.PUBLIC.GLOBAL_FINAI_ANALYTICS` semantic view with natural language, get SQL + results back
2. **Cortex Search** — query `FINAI_AUDIT_DB.PUBLIC.finai_handbook_search` to retrieve regulatory handbook citations
3. **Cortex LLM** (`snowflake.cortex.Complete`) — synthesize the structured data + regulatory citations into a unified audit report

Key libraries available: `snowflake-connector-python`, `snowflake.core` (Cortex Search SDK), `python-dotenv`, `streamlit`. Credentials are in `.env`.

## Implementation steps

Rewrite `app.py` with this architecture:

1. **Connection setup** — Use `snowflake.connector` with credentials from `.env`. Cache the connection in `st.session_state`.

2. **Cortex Analyst helper** — `send_analyst_message(prompt)` calls `POST /api/v2/cortex/analyst/message` with `semantic_view: "FINAI_AUDIT_DB.PUBLIC.GLOBAL_FINAI_ANALYTICS"`. Extracts SQL and text from the response, executes the SQL, returns a DataFrame + explanation.

3. **Cortex Search helper** — `search_handbook(query)` uses the `snowflake.core.Root` Python SDK to query `finai_handbook_search`, returning matching regulatory text chunks.

4. **LLM synthesis helper** — `synthesize_report(question, analyst_result, handbook_citations)` calls `snowflake.cortex.Complete` to produce a unified markdown audit report combining the data findings with regulatory citations.

5. **Chat UI** — Replace the hardcoded `st.text_input` flow with `st.chat_message` / `st.chat_input` for a proper multi-turn chat. Each user message triggers all three steps in sequence under a spinner, then renders the synthesized report.

6. **Sidebar** — Keep the existing sidebar indicators (connected status, flagged accounts) but make them dynamic from a quick SQL count query.
